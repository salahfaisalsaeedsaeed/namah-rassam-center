محرر المحتوى التجريبي — Content Draft Editor

يمكنك مراجعة بيانات الدراسات والفرص والأخبار، وتعديل JSON ثم تنزيل النسخة المعدّلة لرفعها إلى GitHub. هذا المحرر لا ينشر تلقائيًا، ولا يطلب كلمة مرور أو رمز GitHub.

مهم: هذه أداة لإعداد مسودات الملفات فقط. لا توجد صلاحية كتابة للمستودع ولا نظام دخول أو إدارة مستخدمين. لن تتغير صفحات الموقع حتى تعتمد الملفات عبر GitHub وتحدّث الصفحات المرتبطة عند الحاجة.

اختيار مجموعة البيانات

فحص الجودة قبل النشر

يفحص المحرر بناء JSON وصحة المجالات الأساسية، وروابط HTTPS الرسمية، ويمنع التكرارات البسيطة. لا يحل هذا محل مراجعة المؤلفين والـ DOI والموافقات على النشر.

حدد السجل، ثم اضغط «تحميل البيانات الحالية».

مسار نشر الملف

1. نزّل الملف بصيغة JSON. 2. افتح مستودع المركز. 3. استبدل الملف المناظر داخل data/ على الفرع التجريبي بعد المراجعة. 4. راجع عرض الصفحات. ملفات الدراسات الجديدة تحتاج أيضًا إنشاء صفحاتها وربطها بالموقع.

قواعد التحرير

  • لا تضف أسماء طلاب أو صورًا أو فيديوهات دون الموافقات المطلوبة.
  • لا تنشر موعد مسابقة أو خبرًا دون مصدر يمكن التحقق منه.
  • لا تُنشئ أسماء مؤلفين أو مؤسسات أو أرقام DOI من التخمين.
  • الفرع التجريبي ليس موقع الإنتاج.
