# Research Presentations | العروض التقديمية للأبحاث

هذا المجلد مخصّص لرفع **العروض التقديمية للأوراق البحثية بصيغة PDF**، تمهيدًا لعرضها داخل قسم **Publications → Research Presentations** في موقع مركز نعمة رسام للأبحاث والدراسات.

This folder stores **research-paper presentations in PDF format** for future display under **Publications → Research Presentations** on the bilingual center website.

## رفع الملفات | Upload

1. افتح هذا المجلد على GitHub.
2. اختر **Add file → Upload files**.
3. ارفع ملفات العروض بصيغة **PDF** مع استخدام اسم وصفي وفريد لكل عرض، مثل `2026-short-research-title-presentation.pdf`.
4. اضغط **Commit changes**.

## بيانات العرض | Presentation metadata

لربط العرض بالورقة المنشورة وعرضه بشكل أكاديمي، يُفضّل توفير:
- عنوان العرض / Presentation title
- عنوان الورقة البحثية المرتبطة / Related research paper title
- رقم DOI للورقة (إن وجد) / Related paper DOI (if available)
- أسماء مقدمي العرض / Presenters
- اسم المؤتمر أو الفعالية وسنة العرض / Event and presentation year

## ملاحظات | Notes

- رفع الملفات هنا **لا يجعلها تظهر تلقائيًا على الموقع**؛ تُضاف لاحقًا إلى واجهة Research Presentations باللغتين العربية والإنجليزية مع معاينة الصفحة الأولى.
- ارفع العروض المسموح بنشرها للجمهور فقط.
- احتفظ بأسماء الملفات بعد ربطها بالموقع لتجنّب تعطل الروابط.
