# Published Research Papers | الأوراق البحثية المنشورة

هذا المجلد مخصص لحفظ **النسخ المسموح قانونيًا بنشرها** من الأوراق البحثية التابعة لمركز نعمة رسام للأبحاث والدراسات، لإتاحتها لاحقًا عبر قسم «المنشورات» في الموقع باللغتين العربية والإنجليزية.

This directory stores **lawfully shareable copies** of published research papers intended to be linked from the center's bilingual Publications pages.

## طريقة رفع الأوراق | Upload instructions

1. افتح هذا المجلد على GitHub، ثم اختر **Add file → Upload files**.
2. ارفع ملفات الأوراق بصيغة PDF (نسخة الناشر إذا كان الترخيص يسمح، وإلا النسخة المقبولة للمؤلف عند السماح بإيداعها).
3. استخدم أسماء ملفات واضحة **بالأحرف الإنجليزية والأرقام والشرطات**، مثل:
   `2026-short-paper-title.pdf`
4. اضغط **Commit changes** لحفظ الملفات داخل المستودع.

## بيانات كل ورقة مطلوبة للعرض على الموقع | Required metadata

لكل ورقة، يرجى تزويدنا بالمعلومات التالية لاستعراضها في صفحة Publications بصورة أكاديمية:

- **Full paper title / العنوان العلمي الكامل**
- **Authors / جميع المؤلفين بالترتيب**
- **Publication year / سنة النشر**
- **Journal or conference / المجلة أو المؤتمر**
- **DOI / رابط المعرف الرقمي** (إن وجد)
- **Publication type / نوع المنشور** (Journal Article, Conference Paper, Review, ...)
- **PDF filename / اسم ملف PDF المرفوع**
- **Abstract and keywords / الملخص والكلمات المفتاحية** (عند توفرها)
- **License / التصريح بإتاحة النص الكامل** (عند الحاجة)

## ملاحظات مهمة | Important notes

- **لا تظهر ملفات PDF تلقائيًا في صفحة `publications.html` بمجرد رفعها.** لإظهارها للزائر، يجب إضافة بياناتها وروابطها إلى واجهة المنشورات العربية `publications.html` والإنجليزية `en/publications.html` أو إلى فهرس بيانات يُطوَّر لاحقًا.
- لا ترفع ملفات غير منشورة أو سرية أو لا تملك حق نشرها للعموم؛ هذا مستودع GitHub **عام**، وستكون الملفات المرفوعة إليه متاحة للجميع.
- لا تُحذف ملفات PDF أو يُعاد تسميتها بعد ربطها بصفحة المنشورات إلا مع تحديث الروابط.
- يمكن ربط المقال بالـ DOI بدل استضافة نسخة PDF إذا لم يكن رفع النص الكامل مسموحًا.
