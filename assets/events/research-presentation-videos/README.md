# Research Presentation Videos | فيديوهات العروض البحثية

هذا المجلد مخصص لفيديوهات الطالبات أثناء تقديم الدراسات والأبحاث، لإضافتها لاحقًا إلى قسم **Events → Research Presentation Videos** وربطها بالأوراق البحثية والعروض التقديمية في **Publications**.

This folder is intended for student research-presentation videos to be displayed in a future **Events → Research Presentation Videos** section and connected to the corresponding papers and PDF presentations under **Publications**.

## طريقة الرفع | Upload

1. افتح هذا المجلد على GitHub ثم اختر **Add file → Upload files**.
2. يُفضّل رفع فيديوهات **MP4 (H.264/AAC)** مُحسّنة الحجم.
3. استخدم أسماء واضحة وفريدة، مثل `2026-research-topic-student-presentation.mp4`.
4. اضغط **Commit changes** لإتمام الرفع.
5. إذا رفض GitHub الملف بسبب حجمه، لا تقسّمه عشوائيًا؛ استخدم استضافة فيديو مناسبة وسنربط الفيديو بموقع المركز لاحقًا.

## بيانات تساعد على عرض الفيديو | Suggested metadata

- **عنوان الدراسة** / Research paper title
- **اسم الطالبة أو أسماء الطالبات المقدّمات** / Presenter(s)
- **اسم المؤتمر أو الفعالية** / Event or conference
- **تاريخ العرض** / Presentation date
- **DOI للورقة ذات الصلة (إن وُجد)** / Related paper DOI
- **اسم ملف العرض التقديمي PDF (إن وُجد)** / Related presentation PDF filename

## مهم | Important

- تأكد من الحصول على الموافقات اللازمة لنشر صور الطالبات وأصواتهن على موقع عام، ولا سيما الطالبات القاصرات.
- الملفات المرفوعة إلى المستودع العام ستكون متاحة للجميع.
- رفع الفيديو إلى هذا المجلد لا يعرضه تلقائيًا على الموقع؛ يلزم إضافته إلى صفحة الفعاليات وربطه ببياناته.
- يُفضّل عدم رفع فيديوهات كبيرة إلى GitHub لأنه مستودع ملفات موقع وليس منصة استضافة فيديو متخصصة.

Upload only with appropriate consent for public sharing, especially where presenters are minors. A public GitHub repository makes uploaded files publicly accessible. Files will **not** appear automatically on the Events page.
